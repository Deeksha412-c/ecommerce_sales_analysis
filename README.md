# E-Commerce Sales Analysis

## 1. Project Overview

This project performs an analysis of e-commerce sales data using Python.

The project follows a complete data analysis workflow:

1. Load the dataset
2. Explore the data
3. Clean and validate the data
4. Perform sales analysis
5. Create visualizations
6. Identify meaningful business insights

The project uses Pandas for data analysis and Matplotlib for data visualization.

---

## 2. Objectives

The main objectives of this project are:

- Analyze e-commerce sales data
- Calculate total revenue and quantity sold
- Analyze sales performance by product
- Analyze sales performance by region
- Identify the best-performing product
- Identify the best-performing region
- Visualize sales data using different chart types
- Generate meaningful business insights

---

## 3. Dataset Description

The dataset contains 100 sales records and 7 columns.

### Columns

| Column | Description |
|---|---|
| Date | Date of the transaction |
| Product | Product purchased |
| Quantity | Number of units sold |
| Price | Price of the product |
| Customer_ID | Unique customer identifier |
| Region | Sales region |
| Total_Sales | Total sales amount |

### Dataset Quality

- Total records: 100
- Total columns: 7
- Missing values: 0
- Duplicate records: 0
- Unique products: 5
- Unique regions: 4
- Unique customers: 100
